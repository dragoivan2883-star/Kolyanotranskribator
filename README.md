# Колянотранскрибатор (Kolyanotranskribator)

**Колянотранскрибатор** — разрабатываемое локальное приложение для Windows, которое преобразует речь из аудио- и видеофайлов в обычный текст.

> **Статус:** проект на раннем этапе. Перечисленные возможности — требования к первой версии, а не заявление о том, что они уже работают.

## Как должна работать первая версия

Приложение использует две папки:

- **`Входящие/`** — сюда пользователь кладёт записи на расшифровку.
- **`Исходящие/`** — после успешной обработки здесь появляются исходный аудио-/видеофайл и одноимённая расшифровка в **`.txt`**.

Например, файл `Входящие/Встреча.mp4` после успешного распознавания перемещается в `Исходящие/Встреча.mp4`, а рядом появляется `Исходящие/Встреча.txt`.

При ошибке исходный файл остаётся во «Входящих» для повторной попытки; приложение показывает понятное сообщение. Существующие файлы не должны перезаписываться.

## Возможности MVP

- [ ] Одно окно Windows на русском языке.
- [ ] Автоматическое создание двух рабочих папок.
- [ ] Кнопки открытия папок и запуска обработки входящих файлов.
- [ ] Локальная транскрибация аудио и видео.
- [ ] Автоматическое определение языка речи, сохранение текста на языке записи.
- [ ] Последовательная обработка файлов без зависания окна.
- [ ] Сохранение `.txt` в UTF-8 и перенос оригинала в «Исходящие» при успехе.
- [ ] Понятные сообщения об ошибках.
- [ ] Автоматическое удаление временных файлов, в том числе после ошибок.

**Не включаем в первую версию:** встроенное редактирование и просмотр текста, историю, таймкоды, разделение по говорящим, сложную очередь и дополнительные настройки.

## Планируемые технологии

- **C# / WPF** — интерфейс Windows.
- **whisper.cpp** и многоязычная модель **Whisper small** — распознавание речи на процессоре.
- **FFmpeg** — подготовка аудио из разных форматов и видео.
- **.NET** — среда выполнения; цель — переносимая поставка со всеми необходимыми зависимостями.

Детали сборки, фактические зависимости и производительность будут уточнены по мере появления и тестирования кода.
