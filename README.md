# Колянoтранскрибатор (Kolyanotranskribator)

**Колянoтранскрибатор** — проект приложения для преобразования аудио- и видеозаписей в текст.

Цель проекта — сделать работу с речевыми записями проще: загрузить файл, получить текстовую расшифровку и использовать её для заметок, документов или дальнейшей обработки.

> **Статус:** ранняя стадия разработки. Документация будет дополняться по мере появления исходного кода и реализации функций.

## Для чего создаётся приложение

Расшифровка записей вручную занимает много времени. Приложение задумано как инструмент, который поможет переводить речь из аудио и видео в удобный для чтения и редактирования текст.

Возможные сценарии использования:

- расшифровка встреч, интервью и разговоров;
- подготовка конспектов по лекциям и выступлениям;
- получение текста из видеозаписей;
- создание черновиков заметок и документов на основе записи.

## Планируемые возможности

Это **план разработки**, а не список уже работающих функций.

- [ ] Загрузка аудиофайлов.
- [ ] Загрузка видеофайлов и извлечение из них звуковой дорожки.
- [ ] Автоматическое распознавание речи и преобразование её в текст.
- [ ] Просмотр полученной расшифровки.
- [ ] Копирование или сохранение результата в текстовом формате.
- [ ] Обработка ошибок и понятные сообщения о ходе работы.

После появления первой рабочей версии можно рассмотреть дополнительные функции: временные метки, разделение реплик по говорящим, поддержку разных языков и другие форматы экспорта. Их реализация пока не подтверждена.

## Предполагаемый процесс работы

1. Пользователь выбирает аудио- или видеофайл.
2. Приложение подготавливает аудиоданные для распознавания.
3. Механизм транскрибации преобразует речь в текст.
4. Пользователь просматривает и сохраняет результат.

Конкретный механизм распознавания речи и детали обработки будут описаны после выбора и реализации технического решения.

## Конфиденциальность записей

Аудио и видео могут содержать персональные или конфиденциальные сведения. До выбора механизма распознавания речи **нельзя гарантировать**, что обработка будет полностью локальной или что файлы не будут передаваться внешнему сервису. Порядок обработки и хранения данных будет отдельно описан после реализации.
