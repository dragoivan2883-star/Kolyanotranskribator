# Колянотранскрибатор

Локальное приложение Windows для расшифровки аудио и видео. Первая версия работает с папками `Входящие` и `Исходящие`.

## Запуск

1. Подготовьте сборку по инструкции ниже. Скопируйте **всю** папку `dist/Kolyanotranskribator` в доступное для записи место. Откройте `Kolyanotranskribator.exe` двойным щелчком.
2. Нажмите «Открыть Входящие» и положите туда записи. Поддерживаются WAV, MP3, M4A, OGG, FLAC, MP4, MOV, MKV и WebM.
3. Нажмите «Обработать входящие». Окно покажет этап и результат каждого файла.
4. Нажмите «Открыть Исходящие». После успеха там находятся исходная запись и текстовый файл UTF-8 с общим именем. При совпадении имени добавляется `(2)`, `(3)` и далее.

Если обработка не удалась, оригинал остаётся во «Входящих». Приложение продолжает со следующим файлом. При обычной работе интернет не требуется.

Модель Whisper временно копируется в `C:\Users\Public\Kolyanotranskribator`, чтобы Windows-сборка `whisper-cli` могла читать её даже при русских буквах в имени профиля. Временные аудиофайлы в подпапках `job-*` удаляются после обработки.

## Разработка и компоненты

Установите .NET 10 SDK и запустите в PowerShell из корня репозитория `powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1`. Скрипт загрузит FFmpeg, whisper.cpp и модель, проверит контрольную сумму модели, соберёт автономное приложение и поместит все компоненты в `dist/Kolyanotranskribator`. Эта папка создаётся локально и в Git не хранится.

- .NET SDK 10.0.403 — [Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).
- FFmpeg 9.0.2 essentials — [сборка gyan.dev](https://www.gyan.dev/ffmpeg/builds/).
- whisper.cpp 1.9.5, Windows x64 CPU, сборка `b5454` — [релизы проекта](https://github.com/ggml-org/whisper.cpp/releases).
- Многоязычная `ggml-small.bin` — [модель проекта](https://huggingface.co/ggerganov/whisper.cpp). SHA-256 `1BE3A9B2063867B937E64E2EC7483364A79917E157FA98C5D94B5C1FFFEA987B`.

## Проверка на этом ноутбуке

Тестовый образец создан установленным голосом Windows `Microsoft Irina Desktop`. Исходный текст находится в `samples/reference.txt`. Длительность образца — 71,32 с. Полный цикл FFmpeg → Whisper small занял 20,09 с при повторном запуске с уже подготовленной копией модели. Текст в целом совпал, но встречаются ошибки отдельных слов. Это проверка на синтезированной речи, скорость и качество на живой записи могут отличаться.
